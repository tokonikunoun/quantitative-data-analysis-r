# Week 2 — Confidence Intervals and Statistical Distributions

## Project Overview

This independent practical explores statistical inference using the Auto MPG dataset and R programming.

The analysis focuses on descriptive statistics, confidence interval estimation, sample proportions and statistical distributions.

**Module:** CS5701 — Quantitative Data Analysis  
**Programme:** MSc Artificial Intelligence  
**University:** Brunel University London

## Dataset

**Name:** Auto MPG  
**Source:** UCI Machine Learning Repository

The dataset contains information about vehicle fuel efficiency and characteristics, including acceleration, weight, horsepower and model year.

## Learning Objectives

- Import and explore a real-world dataset using R.
- Examine distributions of continuous variables.
- Calculate and interpret confidence intervals for population means.
- Estimate the proportion of vehicles manufactured in the 1980s.
- Calculate and interpret confidence intervals for population proportions.
- Explore the relationship between confidence level and interval width.

## Tools and Technologies

- R
- RStudio
- R Markdown
- Base R statistical functions
- Git and GitHub

## Analysis Highlights

The analysis includes a 95% confidence interval for mean vehicle acceleration and an estimate of the proportion of cars manufactured in the 1980s.

In the analysed dataset, approximately **22.4%** of vehicles were manufactured in the 1980s.

The analysis also examines the interpretation of confidence intervals and their role in statistical inference.
