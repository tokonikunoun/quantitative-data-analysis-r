# Quantitative Data Analysis with R

### Exploratory Data Analysis of the Diamonds Dataset

An independent data analysis project completed using **R, RStudio, R Markdown, and ggplot2**, as part of my MSc Artificial Intelligence studies at Brunel University London.

## Project Overview

This project explores the `diamonds` dataset available in the `ggplot2` R package. The dataset contains approximately 54,000 diamond observations, including information about prices, carat weights, cut quality, colour, clarity, and physical dimensions.

The project focuses on applying foundational quantitative data analysis techniques to understand the dataset's structure, distributions, data quality, and relationships between variables.

## Objectives

The analysis is organised around five objectives:

1. **Data exploration:** Examine the dataset's structure, dimensions, variables, and data types.
2. **Data validation:** Compare observed values with documented ranges and investigate potential inconsistencies.
3. **Descriptive statistics:** Produce appropriate numerical summaries for categorical and continuous variables.
4. **Data visualisation:** Create informative plots to explore distributions and patterns.
5. **Exploring relationships:** Investigate associations between categorical and continuous variables.

## Dataset

**Dataset:** `diamonds`  
**Source:** ggplot2 R package  
**Observations:** Approximately 54,000  
**Variables:** 10

The dataset includes diamond price, carat, cut, colour, clarity, depth, table, and physical dimensions (`x`, `y`, `z`).

## Methodology

The project follows an exploratory data analysis workflow:

1. Load and inspect the dataset.
2. Verify variable definitions and investigate documented value ranges.
3. Calculate numerical summaries appropriate to each variable type.
4. Generate labelled statistical visualisations.
5. Explore relationships between variables.
6. Document observations and limitations.

## Reproducing the Analysis

Clone this repository and open the RStudio project.

Install the required package if necessary:

```r
install.packages("ggplot2")
```

Load the package and dataset:

```r
library(ggplot2)
data("diamonds")
```

Open the R Markdown analysis file and run its code chunks or knit the document to reproduce the report.
